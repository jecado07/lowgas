## 🚀 Demo en Vivo

🌐 **[Abrir LowGas](https://lowgas.netlify.app/)**

## ✨ Características

- ⚡ Interfaz web rápida, moderna y ligera
- 📱 Diseño responsive adaptado a móviles y escritorio
- 🛠️ Código limpio estructurado en HTML5, CSS3 y JavaScript vanilla
- 🚀 Configuración y despliegue automatizado con Netlify

## 🛠️ Stack Tecnológico

- HTML5 · CSS3 · JavaScript Vanilla · Netlify

## 📦 Instalación Local

```bash
# 1. Clonar repositorio
git clone https://github.com/jecado07/lowgas.git

# 2. Entrar a la carpeta
cd lowgas

# 3. Abrir index.html en el navegador
```
